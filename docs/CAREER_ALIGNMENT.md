# 2026 年大厂面经考点与求职交付物映射

项目同时针对两条主线：**Agent/RAG/AI 应用开发** 与 **LLM 算法/后训练/Agentic RL**。面经是候选人的自述，不能将帖文统计当作企业官方命题概率。

## 面试问题与模块对应

| 面试问题类型 | 对应模块 | 需要能展示的证据 |
|---|---|---|
| RAG 为何采用 Hybrid/RRF/Rerank？ | W3–W4 | 同数据集四种方案的 Recall/MRR/nDCG、延迟、失败案例 |
| 如何防止引用过期文档？ | W2–W4 | 文档版本、有效期过滤、溯源测试 |
| 为什么选择 LangGraph？ | W5 | 图状态、Checkpoint、崩溃恢复测试 |
| MCP 与普通函数调用有何区别？ | W6 | MCP Server/Client 与 Tool Schema，权限边界 |
| 工具重复执行会不会造成重复工单？ | W6–W7 | 幂等键、唯一约束、写入重试集成测试 |
| 多租户能否查到其他客户的数据？ | W7 | 非法访问测试、后端/RLS 过滤、审计日志 |
| Agent 怎么评测，失败如何归因？ | W8 | 初始/最终状态、独立 Verifier、Trace 和 Bad Case 分类 |
| 高并发下延迟瓶颈在哪？ | W9–W10 | 固定条件负载测试与 P95 分析 |
| SFT 数据怎么构造？ | W11 | 轨迹构造脚本、数据过滤、消融与泛化测试 |
| GRPO Reward 设计及 Reward Hacking 如何处理？ | W12 | 实际训练配置、环境奖励、成功率与负例 |

## 最终应交付的求职材料

1. **运行材料**：一键部署、演示视频、演示任务和回退方案。
2. **算法材料**：RAG 实验报告、Agent 成功率评测、如有则 SFT/GRPO 报告。
3. **工程材料**：系统设计图、API 文档、安全与异常恢复测试、性能测试。
4. **简历素材**：算法版和应用版分别强调成果，填入的成绩须由实际实验计算。
5. **面试答辩稿**：架构取舍、失败场景、性能瓶颈、算法损失和训练/测试隔离。

## 推荐简历叙述框架（不含虚构指标）

- **应用版**：负责企业级 Agent 执行平台的 RAG 检索、LangGraph/MCP 工具编排、租户权限、故障恢复与性能验证；使用固定评测集比较检索及执行策略。
- **算法版**：基于可验证的模拟业务环境构建 Agent 轨迹数据、状态评分与训练评估流水线；对比基础策略、SFT 和资源允许时的 GRPO，分析 Reward、工具调用错误及泛化能力。

项目交付前不得把“拟实现”写成“已落地”，不得凭空填入提升百分比和成本节省数据。
