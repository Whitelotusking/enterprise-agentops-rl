# 04｜查询参数：在函数参数中声明

> 来源：[FastAPI 官方中文教程 · 查询参数](https://fastapi.tiangolo.com/zh/tutorial/query-params/)（教程第三部分）

## 核心知识

**路径参数写在路由地址里，查询参数写在函数参数里。**

- **路径参数**：在装饰器的 URL 中用 `{变量名}` 声明，如 `/items/{item_id}`。
- **查询参数**：基础类型参数不在路径里时，FastAPI 会将它识别为查询参数；可以直接在函数中设置默认值。

## 代码示例

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
def get_item(item_id: int, skip: int = 0, limit: int = 10):
    return {"item_id": item_id, "skip": skip, "limit": limit}
```

访问 `/items/5?skip=2&limit=20`，返回：

```json
{"item_id": 5, "skip": 2, "limit": 20}
```

| 参数 | 类型 | 从哪里获取 |
|---|---|---|
| `item_id` | 路径参数 | `/items/5` 中的 `5` |
| `skip`、`limit` | 查询参数 | `?` 后的 `skip=2&limit=20` |

## 注意事项

1. **有默认值**（如 `limit: int = 10`），请求中可以不传；不传就使用默认值。
2. **没有默认值就变成必选查询参数**。例如 `q: str`，请求必须提供 `?q=内容`，否则 FastAPI 返回 **422 参数校验错误**。
3. 查询参数以 `?` 开始，多个参数通过 `&` 连接；**不需要**在 `@app.get(...)` 中写出这些参数名。

## 项目中的应用

查询工单列表时，可以使用 `GET /tasks?skip=0&limit=20` 分页；查看单个工单则使用 `GET /tasks/{task_id}`。
