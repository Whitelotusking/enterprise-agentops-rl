# FastAPI 01：基础概念、实例、装饰器与路由

来源：[FastAPI 中文教程：第一步](https://fastapi.tiangolo.com/zh/tutorial/first-steps/)  
整理日期：2026-10-26

## 一句话记住

**FastAPI 让 Python 函数成为可以通过 HTTP 调用的 API。** 它负责接收请求、校验数据、调用业务逻辑并返回响应；它本身不是数据库、RAG 或大模型。

## 最小示例

```python
from fastapi import FastAPI

app = FastAPI()                # 创建 FastAPI 应用实例

@app.get("/")                  # 注册 GET / 路由
async def root():
    return {"message": "Hello World"}
```

启动（从 `backend` 目录）：

```bash
../.venv/bin/python -m uvicorn learn_fastapi:app --reload --port 8001
```

访问 `http://localhost:8001/`，返回：

```json
{"message": "Hello World"}
```

访问 `http://localhost:8001/docs`，可以看到自动生成的 API 测试页面。

## 重点 1：`app = FastAPI()`

- `FastAPI` 是类，`app` 是我们创建的应用**实例对象**。
- 后面的 `@app.get(...)`、`@app.post(...)` 都在这个应用中注册接口。
- **不要混淆**：创建了 `app` 不等于启动了服务器。通常还需要通过 Uvicorn 启动。

## 重点 2：`@app.get("/")` 是什么

`@` 开头的是 Python **装饰器**。一般的装饰器可以为函数附加能力；FastAPI 的 `@app.get("/")` 是**路径操作装饰器**，用来注册“遇到 GET / 时调用下面的函数”的规则。

```text
浏览器 GET /
   ↓
FastAPI 匹配 @app.get("/")
   ↓
执行 root()
   ↓
将 dict 转成 JSON 响应
```

如果只有 `root()`，没有 `@app.get("/")`，FastAPI 不会自动把它当作 HTTP 路由。

## 重点 3：GET 和 POST

| 请求方法 | 常见用途 | 我们项目中的例子 |
|---|---|---|
| GET | 查询已有资源 | `GET /tasks/{task_id}`：查看任务 |
| POST | 提交数据、创建资源或触发处理 | `POST /tasks`：新建任务 |
| PATCH | 局部更新 | `PATCH /tasks/{task_id}`：更新状态 |
| DELETE | 删除资源 | `DELETE /tasks/{task_id}` |

这些是常见的 REST 约定；GET 通常不应产生业务写入副作用。

## `async def` 先理解到什么程度？

它表示异步函数。对于调用外部 HTTP API、数据库等**支持异步的等待操作**，可以提高服务器处理并发请求的能力；但它不会让 CPU 计算或阻塞函数自动变快。

现在先认识写法，后续学习异步数据库和模型 API 时再深入。

## 和 Enterprise AgentOps-RL 的关系

```text
前端提交客户咨询
      ↓
FastAPI（POST /tasks：接收并验证请求）
      ↓
业务服务 / Agent Harness / RAG / MCP
      ↓
PostgreSQL 存任务状态
      ↓
FastAPI 将结果返回前端
```

FastAPI 主要是**服务入口**，权限、审批、数据库事务和工单业务规则需由服务端的业务代码保障。

## 顺带了解：FastAPI Cloud

FastAPI Cloud 是托管/部署 FastAPI 服务的云平台，**不是 FastAPI 框架本身**，也不是学习路由的前置条件。我们目前使用 WSL + Uvicorn 本地开发即可。
