# FastAPI 03：WSL + VS Code 的学习环境

整理日期：2026-10-26。针对本项目已配置的本地环境，不是通用安装教程。

## 文件该放哪里？

```text
enterprise-agentops-rl/
├── .venv/                  # Python 虚拟环境（不改动）
└── backend/
    ├── app/
    │   └── main.py         # 正式项目入口，学习时不要覆盖
    └── learn_fastapi.py    # 官方教程练习文件（本机已创建）
```

WSL 中项目目录：

```text
/home/enterprise/projects/enterprise-agentops-rl
```

打开的是 Linux 内部目录，而不是 Windows 下 `J:\enterprise` 这个外层目录。

## 打开和配置 VS Code

1. Windows 终端运行 `wsl -d enterprise-ubuntu`，或在 VS Code 里选择 **WSL: Connect to WSL using Distro**，连接 `enterprise-ubuntu`。
2. 在 VS Code 打开 `/home/enterprise/projects/enterprise-agentops-rl`。
3. 扩展 **Python** 和 **Pylance** 应在 WSL 远程环境中启用。
4. `Ctrl+Shift+P`（命令面板，而不是 `Ctrl+P` 文件搜索）→ `Python: Select Interpreter`。
5. 选择解释器 `/home/enterprise/projects/enterprise-agentops-rl/.venv/bin/python`。

若输入命令时出现 “No matching results”，先确认是不是误用了文件搜索框：命令面板也可在搜索框前加 `>`。

## 启动教程示例

在 VS Code 的 WSL 终端运行：

```bash
cd ~/projects/enterprise-agentops-rl
source .venv/bin/activate
cd backend
python -m uvicorn learn_fastapi:app --reload --port 8001
```

- `learn_fastapi:app` = `learn_fastapi.py` 文件里的 `app` 对象。
- `--reload` = 修改文件时开发服务器自动重启（只用于开发）。
- `--port 8001` = 避免占用正式项目的 8000 端口。
- `http://localhost:8001/` 查看示例返回。
- `http://localhost:8001/docs` 用交互文档测试接口。
- 按 `Ctrl+C` 关闭服务器。

### 快速检查 FastAPI 是否可导入

```bash
cd ~/projects/enterprise-agentops-rl
.venv/bin/python -c "import fastapi; print(fastapi.__version__)"
```

## 避坑

- VS Code **编辑器**和 WSL **运行环境**是两个概念；解释器要选项目 `.venv`。
- 不要每次跟教程都 `pip install` 或重建虚拟环境；本机已安装并验证 FastAPI。
- `backend/app/main.py`（正式服务）与 `backend/learn_fastapi.py`（学习示例）是两个不同的应用入口。
- 当前 WSL 项目曾通过 GitHub ZIP 快照导入，本地是否有 `.git` 须先确认；**GitHub 上的 notes 更新不会自动同步到 VS Code**。
