# 02｜路径参数：固定路径要写在动态路径前面

> 来源：[FastAPI 官方中文教程 · 路径参数](https://fastapi.tiangolo.com/zh/tutorial/path-params/)

## 核心知识

**FastAPI 会按照路由的声明顺序进行匹配。**

当固定路径与动态路径可能匹配同一个请求时，如果把动态路径 `/users/{user_id}` 放在前面，它会先接收 `/users/me`，把 `me` 当作 `user_id`，导致后面专门定义的 `/users/me` 路由无法被执行。

**记住：固定路径在前，动态路径在后。**

## 正确写法

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/me")  # 固定路径：先写
def get_me():
    return {"user": "当前用户"}

@app.get("/users/{user_id}")  # 动态路径：后写
def get_user(user_id: str):
    return {"user_id": user_id}
```

| 访问地址 | 执行结果 |
|---|---|
| `GET /users/me` | `{"user": "当前用户"}` |
| `GET /users/123` | `{"user_id": "123"}` |

## 容易踩的坑

如果把上面两个路由的位置**交换**，访问 `/users/me` 就会先命中 `/users/{user_id}`，返回 `{"user_id": "me"}`，而不是调用 `get_me()`。

即使把 `user_id` 改成 `int`，也不会自动跳到后面的固定路由，而是可能返回 **422 参数校验错误**。

## 路径转换器：接收包含斜杠的路径

普通的 `{file_path}` 只匹配一个路径片段；如果参数里还包含 `/`，就要使用 **`{file_path:path}`**：

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

- **`:path`**：允许 `file_path` 接收包含 `/` 的完整路径。
- **`file_path: str`**：接收到的是**路径字符串**，不是文件内容，也不会自动打开文件。

例如访问 `/files/docs/report.txt`，返回 `{"file_path": "docs/report.txt"}`。

**注意：** 若要传入以 `/` 开头的绝对路径，如 `/home/user/a.txt`，URL 需要写成 `/files//home/user/a.txt`（`files` 后两个斜杠）。

> 在真实项目中，接收路径字符串 ≠ 允许访问任意文件。若要读取文件，还必须校验路径和访问权限。

## 项目中的应用

将 `/tasks/latest`（最新任务）写在 `/tasks/{task_id}`（指定任务）之前，避免把 `latest` 误识别成任务 ID。
